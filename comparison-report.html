Общее позиционирование и назначение

AQA · Алматы

Публичный мониторинг для горожан

  • Целевая аудитория: жители Алматы, общество
  • Акцент на PM2.5 и индексе AQI (US EPA 2024)
  • Плотная сеть из 173 IoT-датчиков AAI + EcoIQ
  • Гиперлокальные данные (уровень района/улицы)
  • Рекомендации по поведению в зависимости от AQI
  • AI-вкладка с аналитикой
  • Данные пыльцы (один датчик)
AUATECH · УК

Регуляторный мониторинг для властей

  • Целевая аудитория: государственные органы, надзор
  • 13 параметров по санитарным нормам РК/ВОЗ
  • 25 официальных постов мониторинга (ГЭМ)
  • Атрибуция промышленных источников
  • Моделирование рассеивания (Impact-расчёт)
  • Реестр инцидентов и превышений
  • Автоматическая генерация Excel-отчётов

Критические разрывы — что нужно построить

P1
Реестр превышений / инцидентов Нет журнала зафиксированных превышений ПДК. Пользователь не может узнать, когда было превышение, на каком датчике и насколько. Это самое очевидное функциональное отсутствие по сравнению с референсом.
P1
Пользовательские уведомления о превышениях Нет алертов по пороговым значениям. Пользователь узнаёт о плохом воздухе только открыв приложение вручную. Нужны push / email / in-app уведомления при превышении AQI-порога.
P1
Экспорт данных (CSV / Excel) Никакой возможности скачать данные нет. Референс генерирует автоматические ежедневные Excel-отчёты. Для профессиональных пользователей — критично.
P1
Переключение параметра в аналитике Вся аналитика заточена только под PM2.5. Нет возможности посмотреть статистику по PM10, CO2, TVOC. Данные в БД есть — нужен UI-переключатель параметра.
P2
Тепловая таблица: посты × период Референс показывает сетку всех постов мониторинга по строкам и параметры/периоды по столбцам, окрашенную по концентрации. Даёт мгновенный обзор «кто грязнее».
P2
Среднее по часам суток и дням недели Паттерны загрязнения по времени суток и дням недели очень полезны для понимания источников (утренний трафик, производственные смены). Уже запланировано в ANALYTICS.md, нужно реализовать.
P3
Роза/диаграмма преобладающих загрязнителей Радиальная диаграмма с разбивкой по месяцам (SO2 28%, PM2.5 23%, PM10 20%…) — наглядный срез структуры загрязнения. Полезна при множестве параметров.
P3
Промышленные параметры (SO2, NO2, H2S) AQA не охватывает газообразные промышленные загрязнители. Для Алматы актуальны NO2 (трафик) и SO2 (ТЭЦ). Расширение зависит от наличия датчиков.

Сильные стороны AQA — что есть у нас, но нет в референсе

173 датчика против 25 постов В 7× больше точек мониторинга — гиперлокальная картина качества воздуха на уровне микрорайона и улицы.
AI-вкладка с интерпретацией данных Автоматические инсайты и рекомендации на основе AQI — уникальная функция, нет в референсной системе.
Данные пыльцы Пыльцевой датчик с 42 параметрами — актуально для аллергиков. Полностью отсутствует в AUATECH.
CO2 и TVOC Данные о содержании углекислого газа и летучих органических соединений — важны для оценки качества воздуха в помещениях и у дороги.
EcoIQ интеграция Двойная сеть: собственные AAI-датчики + сторонняя сеть EcoIQ на одной карте. Перекрёстная верификация данных.
US EPA AQI 2024 Международный стандарт AQI, понятный широкой аудитории, с цветовым кодированием. Референс фокусируется на сырых концентрациях.
Тёмная/светлая тема Полноценная поддержка системной темы — удобство для пользователей в любое время суток.
Карта зданий без газа Специализированный слой для Алматы — выявление источников угольного отопления. Данная функция выходит за рамки мониторинга воздуха.

Итоговая оценка

AQA — выводы

Сильная публичная платформа, слабая операционная

  • Отлично подходит для информирования горожан
  • Лучшее пространственное покрытие (173 датчика)
  • Уникальные параметры: пыльца, CO2, AI-инсайты
  • Нет операционных инструментов: алертов, экспорта, истории превышений
  • Аналитика глубже по временным рядам, но уже по параметрам
  • Нет атрибуции источников и моделирования
AUATECH — выводы

Зрелая регуляторная платформа

  • Полный набор для государственного мониторинга
  • Расчёт вкладов источников — ключевое конкурентное преимущество
  • Автоматические отчёты и реестр инцидентов
  • Меньше датчиков — меньше гиперлокальности
  • Нет AI, рекомендаций, пыльцы, CO2
  • Целевая аудитория — профессионалы, не горожане
